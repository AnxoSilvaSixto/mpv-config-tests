# mpv-config-tests — verification harness for mpv-config

Suites, real-world clips, and shader benchmarks for
[mpv-config](https://github.com/AnxoSilvaSixto/mpv-config)
(portable mpv, RTX 5080 / Vulkan / 1440p@165Hz, faithful anime reconstruction).

## Setup

- Clone next to the config (any folder works):
  `git clone https://github.com/AnxoSilvaSixto/mpv-config-tests.git`
- The harness finds mpv via `MPV_ROOT` (defaults to `C:/mpv`):
  `$env:MPV_ROOT = 'C:/mpv'`
- Requirements: mpv build at `$MPV_ROOT/mpv.exe`, PowerShell 5.1+,
  ffmpeg/ffprobe on PATH (only for `make-test-clips.ps1` and SSIM checks).
- Real clips (`clips/real/`, ~200 MB of anime cuts) are gitignored and stay
  local — re-cut them with `make-test-clips.ps1` (provenance + recipes in
  its header). Missing real clips make `test-realworld.ps1` SKIP, never FAIL.

## Run

- Full suite: `powershell -NoProfile -ExecutionPolicy Bypass -File run-all.ps1`
  (cargo-pretty-style live view: Running timer, Done checkmarks, pinned bar;
  plain streaming fallback when redirected; exit 0 = green. The runner kills
  all mpv instances at start for a clean slate, so close your own
  playback first, and don't play files in mpv *during* a run.)
- Single suite: same invocation with the file, e.g. `... -File test-seek.ps1`
- Benchmark: `bench/bench-shaders.ps1` (stock smoke on the 4 real clips runs
  as the last run-all step; full matrix stays manual):
  `powershell -NoProfile -ExecutionPolicy Bypass -File bench/bench-shaders.ps1`
  - Shootout verdicts: `bench/SHOOTOUT-RESULTS.md` (per-rung winners, rejections).

## Layout

- `clips/` — tiny synthetic clips, regenerated by `make-test-clips.ps1`
  (testsrc/sine + h264_metadata flags; see header for the NTSC/PAL/gray notes)
- `clips/real/` — short real-world cuts (see `make-test-clips.ps1` "real clips"
  section for provenance + cut recipes; sources live outside this repo).
  Gitignored — never pushed.
- `test-*.ps1` — one suite per concern; each plays clips with
  `--vo=null --ao=null` + IPC and asserts auto-profile application from
  `--log-file` (plus `aid`/track checks where relevant). Logs land in %TEMP%.
- `bench/` — `bench-shaders.ps1` (realtime drop-counter bench: stock/nlmeans/
  heavy presets at 2560x1440; method notes + quirks in its header),
  `matrix-*.ps1` + `shootout.ps1` (shader shootout runners), and
  `bench-results.csv` (append-only history for driver/config comparisons).
- `ttfnames.py` — uosc/truetype font-name helper.

## Conventions

- One fix at a time, each landed only after its suite re-runs green.
- Logs must be free of `[fatal]`/`[error]`/`lua error` (checked per suite).
- Close games/background GPU load before timing-sensitive runs
  (seek pacing, bench); on flake, rerun clean before concluding.
